# Sözlük

| Terim | Anlamı |
|---|---|
| Trafo (dağıtım trafosu) | Mahalleyi besleyen, orta gerilimi evlerin 230/250 V'una indiren cihaz. Direk tipi küçük (25–400 kVA), yer tipi büyük (50–2.500 kVA). |
| kVA | Trafonun taşıyabileceği güç. |
| Hat ucu | Trafodan en uzaktaki ev; gerilim en çok orada yükselir. |
| Faz | Mahalle hattındaki üç telden biri. Ev tek fazlıysa birine bağlıdır; panellerin hepsi aynı tele binerse gerilim çok daha hızlı yükselir. |
| Barındırma kapasitesi (hosting capacity) | Şebekeyi bozmadan, yükseltmeden bağlanabilecek ek güneş gücü. Bizde "kaç ev daha sığar". |
| Isıl pay | Trafonun ısınmadan taşıyabileceği ek güç. |
| Gerilim payı | Hat ucundaki gerilimin sınıra (259 V planlama, 264 V inverter kapanması) kalan mesafesi. |
| %40 kuralı | Kıb-Tek'in bugünkü kuralı: bir trafodaki panel toplamı trafo gücünün %40'ını geçemez. |
| Öğlen en düşük yük | Güneşin en güçlü olduğu saatte (11–14) trafonun en az çektiği güç; bahar günlerinde en düşük. Güneş için asıl kritik an. |
| Şablon / arketip | Günlük eğrisi birbirine benzeyen trafoların ortak eğrisi (İngiltere'de 10, bizde 3–6). |
| Şekil ve büyüklük | Şekil: normalize günlük eğri (abone karışımı belirler). Büyüklük: toplam yük (abone sayısı ve tarife sınıfı belirler). |
| Atama (sınıflandırma) | Ölçülmeyen trafoyu, elde olan bilgilerle (kVA, abone karışımı, panel sayısı) bir şablona koymak. |
| Ölçekleme | Şablonun eğrisini trafonun büyüklüğüne göre büyütmek/küçültmek. |
| Bir-trafo-dışarıda (leave-one-out) | Ölçülü bir trafoyu hiç ölçülmemiş gibi tahmin edip gerçeğiyle karşılaştırmak; her trafo için tekrar. |
| P10–P90 bant | Tahminin %80 olasılıkla içinde kalması beklenen aralık. |
| Kalibrasyon | "%80 bandım gerçekten vakaların %80'ini kapsıyor mu" kontrolü. |
| Güven etiketi | Trafo ölçtüğümüz trafolara ne kadar benziyorsa o kadar yüksek güven. |
| Yanlış yeşil | Aslında dolu trafoya "yer var" demek. En pahalı hata. |
| Triyaj | Başvuruları ayırmak: onayla / işaretle / ölç. Ret aracı değil. |
| Alan rastgeleleştirme | Belirsiz ayarları her seferinde değiştirerek çok sayıda farazi şehir üretmek; model tek şehrin varsayımını ezberlemesin diye. |
| Esnek onay | Paneli "gerilim yükselirse gücü uzaktan kısılır" şartıyla hemen bağlamak (Güney Avustralya). |
| ADR | Karar kaydı: bağlam, karar, sonuç, tarih. Düzenlenmez, yerine yenisi yazılır. |
